Clases de Direcciones IP

Red Clase A

Propósito: Diseñada para redes gigantescas (gobiernos, multinacionales, proveedores de internet).

Rango IP: 1.0.0.0 a 126.255.255.255

Máscara por defecto: 255.0.0.0 ( /8 )

Estructura: El primer octeto (8 bits) identifica la red y los 3 octetos restantes (24 bits) se destinan a hosts.

Capacidad: 126 redes y hasta 16,777,214 hosts utilizables por red.

Nota sobre Loopback: El rango 127.0.0.0 a 127.255.255.255 pertenece a la Clase A pero está reservado exclusivamente para diagnóstico local (localhost).

Red Clase B

Propósito: Diseñada para redes medianas a grandes (universidades, corporativos).

Rango IP: 128.0.0.0 a 191.255.255.255

Máscara por defecto: 255.255.0.0 ( /16 )

Estructura: Los primeros 2 octetos (16 bits) identifican la red y los otros 2 octetos se destinan a hosts.

Capacidad: 16,384 redes y hasta 65,534 hosts utilizables por red.

Red Clase C

Propósito: Diseñada para redes pequeñas (LANs domésticas, pequeñas empresas).

Rango IP: 192.0.0.0 a 223.255.255.255

Máscara por defecto: 255.255.255.0 ( /24 )

Estructura: Los primeros 3 octetos (24 bits) identifican la red y el último octeto (8 bits) se destina a hosts.

Capacidad: 2,097,152 redes y hasta 254 hosts utilizables por red.

Red Clase D (Multicast / Multidifusión)

Propósito: Reservada exclusivamente para tráfico de multidifusión (transmisión simultánea a un grupo de equipos, como streaming o protocolos de enrutamiento).

Rango IP: 224.0.0.0 a 239.255.255.255

Estructura: No se asigna a hosts individuales y no utiliza máscaras de subred estándar.

Red Clase E (Experimental)

Propósito: Reservada por la IANA para fines de investigación, desarrollo experimental y uso futuro.

Rango IP: 240.0.0.0 a 255.255.255.254

Estructura: No disponible para uso comercial ni asignación en redes de producción.
